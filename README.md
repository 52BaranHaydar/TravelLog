# TravelLog ✈️

A smart iOS travel planner and journal app built with SwiftUI, MapKit, and CoreMotion.

## Features
- 🗺️ Interactive map with trip locations
- 📅 Trip planning with start/end dates
- 🔍 Location search with MapKit
- 👣 Step counter with CoreMotion
- 📊 Travel statistics (trips, days, steps)
- 📝 Trip notes and journal
- 🔖 Status tracking (Planned, Ongoing, Completed)
- 🔎 Search and filter trips

## Tech Stack
- **SwiftUI** — Modern declarative UI
- **MapKit** — Interactive maps & location search
- **CoreMotion** — Step counting & motion tracking
- **CoreData** — Persistent storage
- **MVVM Architecture** — Clean code structure

## Requirements
- iOS 17+
- Xcode 15+
- Swift 5.9+

## Installation
1. Clone the repo
```bash
   git clone https://github.com/52BaranHaydar/TravelLog.git
```
2. Open `TravelLog.xcodeproj` in Xcode
3. Build and run on simulator or device
